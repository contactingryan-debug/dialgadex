# Raid graphics

Unmodified Pokémon GO assets from
[PokeMiners/pogo_assets](https://github.com/PokeMiners/pogo_assets/tree/db10df75d6f6f92018d9786af0aecc238fecc4ef/Images/Raids),
pinned to commit `db10df75d6f6f92018d9786af0aecc238fecc4ef`.
Artwork belongs to its respective Pokémon GO rights holders; PokeMiners hosts
the extracted game assets. These files are visual options on the Boss List.
Their presentation does not assign a raid difficulty or change calculations.
